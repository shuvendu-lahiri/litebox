# LiteBox NFV reports

[Open the live dashboard](https://shuvendu-lahiri.github.io/litebox/nfv_reports/)
or browse the [GitHub-readable report index](nfv_reports/README.md).

The dashboard indexes published prototype NFV reports and reviewer attempts.
Conditional model refutations are highlighted; missing reports remain explicitly
unknown, not successful zero-finding analyses.

This reports-only branch contains no LiteBox source or executable workflows.
Refresh instructions and the snapshot timestamp are in the report index.
